
Este proyecto es una aplicación web desarrollado en Python mediante Streamlit, y permite explorar y analizar un conjunto de datos de anuncios de venta de autos en Estados Unidos.

Funciona de la siguiente forma:
* **Generador de histograma: un botón que, al ser activado, genera un histograma con el que se puede interactuar para visualizar la distribución del odómetro de los vehículos.
* **Gráfico de dispersión: un botón que genera un gráfico de dispersión que analiza la relación entre el precio de los vehículos y su kilometraje.

Ambos se realizaron utilizando la librería Plotly Exprress, lo que los hace interactivos.
